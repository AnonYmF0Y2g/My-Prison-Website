# My-Prison-Website

A professional, Polish-language demonstration website concept for **Areszt Śledczy w Katowicach**.

> **Important:** This repository contains a fictional design/development demonstration. It is not an official website, does not represent the Polish Prison Service, and must not be used as an official information or contact channel.

## Project direction

- Primary language: Polish
- Design: modern public-sector information portal
- Layout: responsive, mobile-first
- Stack: semantic HTML, CSS and vanilla JavaScript
- Accessibility: keyboard navigation, visible focus, skip link, semantic landmarks, reduced-motion support, responsive navigation and native FAQ disclosures

## Files

- `index.html` — page content and structure
- `styles.css` — visual design and responsive layouts
- `script.js` — responsive navigation, outside-click/Escape handling, and current footer year
- The FAQ uses native HTML disclosure elements, so it works without JavaScript.

## Local preview

Open `index.html` in a modern browser. No build step or package installation is required.

## Source and accuracy

Public factual references are linked to the official Polish Prison Service website. The address and general unit description are based on its public listing. Visiting procedures, dates, phone numbers and other operational details are intentionally not invented; visitors should verify current information through official channels.
